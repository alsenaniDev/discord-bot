# اختبار لعبة الروليت الجماعية

## قبل الاختبار

1. طبّق migration باسم `AddRouletteMultiplayer`.
2. استخدم سيرفرًا على باقة `Pro` أو `Premium`.
3. فعّل مركز الألعاب وحدد روم الألعاب.
4. فعّل لعبة `الروليت` للسيرفر واحفظ إعداداتها.
5. تأكد أن تطبيق Discord يملك `EMBEDDED` وأن واجهة Activity والـ API يعملان.

## المسار الأساسي

1. افتح `/games` من روم الألعاب واختر `الروليت` تحت الألعاب الجماعية.
2. أنشئ غرفة وتأكد من ظهور المضيف كلاعب أول ومن ظهور رسالة الدعوة في روم الألعاب.
3. من حساب Discord آخر اضغط `انضم للتحدي`. يجب أن تفتح الـ Activity وتنتقل إلى نفس الغرفة وتضيف المستخدم تلقائيًا.
4. تأكد أن المضيف وحده يرى زر `بدء اللعبة` وأنه لا يتفعّل قبل بلوغ الحد الأدنى.
5. ابدأ اللعبة ثم اضغط `تدوير الروليت` حتى يبقى لاعب واحد.
6. تحقق من ظهور الفائز، وتحديث أرصدة الفائز والمركز الثاني وبقية المشاركين، ونشر نتيجة الفوز إن كان النشر مفعّلًا.

## حالات الحماية

- محاولة الانضمام مرتين تعرض أن المستخدم منضم مسبقًا.
- الغرفة الممتلئة أو المنتهية لا تقبل لاعبين جدد.
- اللاعب غير المضيف لا يستطيع البدء أو التدوير.
- التدوير بعد اكتمال الغرفة لا يمنح مكافآت إضافية.
- كل مكافأة تنشئ `GameWalletTransaction` واحدة مرتبطة بمعرّف الغرفة، والرصيد لا ينزل تحت الصفر.
- مغادرة المضيف قبل البدء تنقل الاستضافة لأول لاعب؛ وإذا لم يبق لاعب تُلغى الغرفة.
- تعطيل نشر الفائز يمنع إنشاء رسالة النتيجة، وتعطيل إعلان الغرفة يمنع رسالة الدعوة.

التحديث اللحظي في هذه المرحلة يعتمد على polling كل 2.5 ثانية، ولا يستخدم WebSockets.
