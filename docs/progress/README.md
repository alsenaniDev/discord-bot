# Progress Reports

Task completion reports documenting what was done, decisions made, validation performed, and follow-ups.

---

## Purpose

- Audit trail for significant work
- Context for future developers and AI agents
- Handoff document after each major task

---

## Naming convention

```
YYYY-MM-DD-{task-slug}.md
```

Examples:
- `2026-07-02-unified-permissions.md`
- `2026-07-02-task-000-architecture-handbook.md`

---

## Required sections (major tasks)

1. Summary
2. Objective
3. Architecture decisions (if applicable)
4. Files changed
5. Validation performed
6. Breaking changes
7. Risks
8. Follow-up tasks
