## What this spec defines

| Area | Decision |
|------|----------|
| **IA** | 5 zones max — Status bar, Mission Card, Pulse, Activity, Drawer |
| **Above-the-fold** | 1440×900 — understanding without scroll |
| **Hero** | Dynamic Mission Card — one CTA, state matrix (10 states) |
| **Modes** | Beginner (pre-first-value) vs Veteran (operational) |
| **Pulse** | Compact 6-metric strip — no rings, no giant cards |
| **Activity** | GitHub-style timeline — i18n, icons, linked rows |
| **Secondary** | Context Drawer — modules, billing, setup, help collapsed |
| **Removed** | Shortcuts, resources footer, health ring, duplicate header, permanent billing/modules cards |
