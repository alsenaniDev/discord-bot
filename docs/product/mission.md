# Product Mission

## Mission

Ship a **reliable Discord bot platform** that community owners can configure, staff can operate, and platform admins can monetize — with clear module boundaries and honest subscription tiers.

## Who we serve

| Segment | Need |
|---------|------|
| Small community owners | Welcome, basic logs, easy setup |
| Growing servers | Tickets, moderation, role tools |
| Professional communities | Staff permissions, plan upgrades, audit trails (future) |
| Platform operators | Admin tools, manual billing control |

## What we deliver today

- Invite bot → `/setup` → dashboard configuration → live features
- 6 modules with plan gating
- Role-based staff permissions (unified model)
- Manual upgrade request workflow
- Platform admin panel

## What we explicitly defer

- Payment automation
- Mobile apps
- Full analytics suite
- Plugin marketplace

## Success metrics (future)

| Metric | Target direction |
|--------|------------------|
| Setup completion rate | > 70% of invited guilds |
| Monthly active guilds | Growth |
| Upgrade conversion | Track post-Stripe |
| Support ticket volume per guild | Decrease with better UX |
