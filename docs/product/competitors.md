# Competitors

## Market context

Discord bot market includes general-purpose bots (MEE6, Dyno, Carl-bot) and specialized SaaS dashboards (Ticket Tool, moderation suites).

**Assumption:** Competitive analysis based on public product knowledge, not proprietary data.

## Comparable products

| Product | Strengths | Our differentiation |
|---------|-----------|----------------------|
| **MEE6** | Brand recognition, leveling, moderation | We offer integrated dashboard + modular SaaS + AR i18n |
| **Dyno** | Moderation, auto-mod, free tier | Our subscription module gating + upgrade workflow |
| **Ticket Tool** | Mature ticketing | We bundle tickets with moderation, logs, roles in one platform |
| **Carl-bot** | Reaction roles, tags | We add dashboard management + plan tiers |
| **Apollo / BotGhost** | No-code bot builders | We are code-first platform with focused module set |

## Our current gaps vs competitors

| Area | Competitor baseline | Our status |
|------|---------------------|------------|
| Auto-mod (spam, links) | Common | Not implemented |
| `/ban`, `/timeout` | Standard | Flags exist; commands not implemented |
| Leveling / XP | Popular | Not in roadmap Phase 1–3 |
| Payment automation | Expected at SaaS launch | Manual approval only |
| Uptime SLA / status page | Enterprise bots | Not implemented |
| Plugin ecosystem | BotGhost, others | Phase 4 target |

## Positioning statement

**Integrated modular operations platform for Discord communities** — not a no-code bot builder, not a single-feature bot. Best for owners who want dashboard + bot parity with subscription-controlled modules.
