# اختبار تحسينات تجربة الروليت

## الهدف

التأكد أن لعبة الروليت داخل Discord Activity تبدو كلعبة واضحة وعادلة:

- الأفاتارات والأسماء تظهر في قائمة اللاعبين والعجلة.
- العجلة تقف على نفس اللاعب الذي اختاره السيرفر.
- لا يتم إظهار الإقصاء قبل انتهاء حركة العجلة.
- إذا اللاعب المستهدف لا يملك خصائص متاحة، يتم تنفيذ النتيجة بدون انتظار طويل.
- استخدام الخصائص يظهر كحدث واضح لكل اللاعبين عبر التحديث الدوري.

## سيناريوهات الاختبار

### 1. إنشاء غرفة والانضمام

1. افتح `/games`.
2. ادخل لعبة الروليت.
3. أنشئ غرفة.
4. انضم بلاعب ثاني أو أكثر.

النتيجة المتوقعة:

- تظهر أسماء اللاعبين وأفاتاراتهم إن وجدت.
- المضيف يستطيع بدء اللعبة عند اكتمال الحد الأدنى.

### 2. دقة العجلة

1. ابدأ اللعبة.
2. اللاعب صاحب الدور يضغط "تدوير العجلة".
3. راقب العجلة حتى تنتهي الحركة.

النتيجة المتوقعة:

- العجلة تدور أولًا.
- بعد انتهاء الحركة تظهر النتيجة.
- اللاعب الذي تقف عليه العجلة هو نفس `targetPlayer` القادم من API.
- لا يتم تغيير النتيجة بسبب polling أثناء الدوران.

### 3. لاعب بدون خصائص

1. اجعل اللاعب المستهدف لا يملك خصائص.
2. دوّر العجلة عليه.

النتيجة المتوقعة:

- تظهر رسالة أن اللاعب لا يملك خصائص متاحة.
- لا يوجد انتظار طويل.
- يتم تنفيذ النتيجة تلقائيًا بعد انتهاء حركة العجلة.

### 4. لاعب يملك خصائص

1. اشترِ خاصية للاعب.
2. اجعله مستهدفًا من العجلة.
3. استخدم Shield أو Reverse أو ReSpin.

النتيجة المتوقعة:

- تظهر أزرار الخصائص للاعب المستهدف فقط.
- يظهر حدث واضح لكل اللاعبين في سجل الجولة.
- يظهر شريط حدث للخاصية المستخدمة.

### 5. إعادة اللف

1. استخدم خاصية ReSpin.

النتيجة المتوقعة:

- يختار السيرفر هدفًا جديدًا.
- ترجع الغرفة لحالة pending صحيحة.
- إذا الهدف الجديد لا يملك خصائص، يتم auto-resolve.

### 6. الموبايل

1. افتح Activity من iOS أو Android.
2. انضم لغرفة.
3. جرّب الدوران، استخدام خاصية، والمغادرة.

النتيجة المتوقعة:

- لا تظهر أخطاء 500/403 بسبب join/leave.
- الواجهة تبقى قابلة للاستخدام داخل شاشة Discord.

## ملاحظات تقنية

- لا يوجد WebSocket في هذه المرحلة؛ التحديثات تتم عبر polling.
- أثناء دوران العجلة يتم تأجيل تطبيق نتائج polling حتى لا تتغير النتيجة بصريًا.
- مصدر الحقيقة للهدف هو backend `SpinAsync` وليس حسابات الواجهة.
